# Source credits and redistribution terms

The Agda development runs against a pinned TypeTopology checkout. The Lean development uses mathlib and includes a port of part of an earlier Lean library. The tables identify upstream code incorporated into the source separately from libraries loaded by the checker and mathematical proofs used as references.

## Mathematical sources

Michael Shulman's paper supplies the real-cohesive axioms and the original statements about real analysis and fixed points. Matthew Frank's interpolated bisection is the starting point of the approximate intermediate value proof. The revised orbifold theorem is compared with David Jaz Myers's definitions and theorems. The questions quoted in the guide are credited to the nLab authors, including Anonymouse for the two apartness questions. [Shulman](https://arxiv.org/abs/1509.07584v3) · [Frank](https://lmcs.episciences.org/6636) · [Myers](https://arxiv.org/abs/2205.15887v1) · [nLab questions](shulman.md#the-nlab-open-problems)
