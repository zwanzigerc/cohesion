# Cohesion

## Tight apartness in cohesive homotopy type theory

When is every tight apartness on a discrete type crisply representable?
When is the induced apartness on ♭A decidable? Over crisp excluded middle,
each principle is equivalent to excluded middle in the cohesive mode.
The paper proves these equivalences and the refutations in real cohesion.
The Agda formalization uses the native sharp modality in Agda 2.9.0.
