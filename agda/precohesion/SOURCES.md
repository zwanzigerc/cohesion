# Sources for native precohesion

The only external Agda modules imported by these files are Agda's own primitive and builtin modules. Some proofs have source predecessors even though the build needs no external library.

| Source | Use |
| --- | --- |
| The Agda contributors' [official sharp-modality example](https://github.com/agda/agda/blob/v2.9.0/doc/user-manual/language/flat.lagda.rst) | `NativeSharp` defines ♯ using a single codiscrete field, following the native interface. Agda's [upstream copyright and MIT permission notice](notices/Agda-LICENSE.txt) accompanies it. |
| Martín Escardó and TypeTopology contributors, [`UF/SubtypeClassifier`](https://github.com/martinescardo/TypeTopology/blob/52ed2eb58d72a6bab0dd70480fa73e2291b08219/source/UF/SubtypeClassifier.lagda#L36-L41) (also [lines 202–209](https://github.com/martinescardo/TypeTopology/blob/52ed2eb58d72a6bab0dd70480fa73e2291b08219/source/UF/SubtypeClassifier.lagda#L202-L209)) and [`UF/SubtypeClassifier-Properties`, lines 24–57](https://github.com/martinescardo/TypeTopology/blob/52ed2eb58d72a6bab0dd70480fa73e2291b08219/source/UF/SubtypeClassifier-Properties.lagda#L24-L57). | `SmallPropositionLaws` ports the proof arguments for extensionality and sethood of the type of propositions, using this project's universe levels and representations. The original files were consulted directly. Their [GPLv3 license](notices/TypeTopology-LICENSE.txt) accompanies this source. The module does not import or include a copy of the TypeTopology modules. |
| Nicolai Kraus, Martín Escardó, Thierry Coquand, and Thorsten Altenkirch, [“Generalizations of Hedberg's Theorem”](https://people.cs.nott.ac.uk/psztxa/publ/tlca13-hedberg.pdf). | `SmallPropositions` uses the local form of Hedberg's argument for constant endomaps of identity types. The source adapts this development's earlier decidable-equality proof. TypeTopology uses the lemma for the sethood of Ω; its implementation of the lemma was not the source of the code here. |
| [TypeTopology's quotient library](https://github.com/martinescardo/TypeTopology/tree/52ed2eb58d72a6bab0dd70480fa73e2291b08219/source/Quotient) | `SmallQuotient` and `QuotientTruncations` relate their interfaces to TypeTopology; they did not port its source. `QuotientEffectivity` gives the local argument and records exactly where its universe hypotheses differ from the reference derivation. |
| Michael Shulman, [“Brouwer's fixed-point theorem in real-cohesive homotopy type theory”](https://arxiv.org/abs/1509.07584), Theorem 6.1; this project's earlier RealCohesion and Orbifolds Agda developments. | `NativeFlatIdentity` ports the crisp induction and encode/decode proof from the project's `RealCohesion/DiscreteConnectedTypes`. `SharpPath` and `CrispTruncation` port the corresponding proofs from `Orbifolds/CrispTruncation`. The three source headers record the precise original lines and hashes; their ports use the local foundations, native ♯ and explicit assumptions. |
